# User Management - Admin UI (Optional)

A small React + Vite + Tailwind CSS dashboard for visually exercising the User Management API. This is optional tooling, not part of the assignment's backend deliverable - see the [root README](../README.md#admin-ui-optional) for full setup instructions and what it shows.

Quick start (with the Flask API already running on `http://127.0.0.1:5000`):

```bash
npm install
cp .env.example .env
npm run dev
```

Then open `http://localhost:5173`.
